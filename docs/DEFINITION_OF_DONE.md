# Definition of Done

A task/plan is DONE only when all are true:

- [ ] All acceptance criteria in the plan are met
- [ ] Code follows docs/CODING_STANDARDS.md; build and lint pass
- [ ] i-code-reviewer: no open BLOCKER or MAJOR
- [ ] i-security-reviewer: no open CRITICAL or HIGH
- [ ] i-tester: all business-case scenarios pass; every requirement traced to a test
- [ ] Coverage on changed code ≥ 90% lines / ≥ 80% branches (adjust for your project)
- [ ] No existing test removed or weakened without user approval
- [ ] Docs/CHANGELOG updated if public behaviour changed
- [ ] Handoff notes written; plan status = DONE; PROGRESS.md updated
